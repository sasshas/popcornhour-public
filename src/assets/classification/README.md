# Australian Classification marks

Used by `src/components/media/AuRatingBadge.tsx` on movie pages.

The official classification marks as published by the Australian Government's Classification site
(https://www.classification.gov.au/classification-ratings/what-are-ratings), copied unchanged
(about 157px, transparent PNGs).

| File | Mark |
|---|---|
| `au-g.png` | G |
| `au-pg.png` | PG |
| `au-m.png` | M |
| `au-ma15.png` | MA 15+ |
| `au-r18.png` | R 18+ |
| `au-x18.png` | X 18+ |
| `au-ctc.png` | Check the Classification |

There is no official image for "RC" (Refused Classification), so it keeps a plain text badge. The marks are
Commonwealth of Australia material: they are used here to label ratings in a personal, self-hosted app. If this
repository is ever made public, read the site's rules for reproducing classification markings first.
